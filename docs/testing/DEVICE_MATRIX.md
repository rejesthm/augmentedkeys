## Recording rules

- Add exact hardware and OS facts from the device itself or another recorded authoritative source; do not infer them from a category.
- Record simulator/emulator and physical-device runs separately. A simulator or emulator result does not fill a physical-device requirement.
- One row may link to multiple evidence records only when each tested configuration remains distinguishable.
- Include audio interface and MIDI controller identities only when they were part of the recorded procedure; otherwise mark them `Not applicable` in that evidence record.
- A passing result covers only the recorded commit, configuration, procedure, and acceptance criteria.
