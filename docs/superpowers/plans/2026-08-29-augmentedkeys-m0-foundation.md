> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create and publish a verified Flutter mobile foundation with truthful M0 status, persistent project governance, and a manual L1 report-only Loop Engineering workflow.

**Architecture:** Flutter owns only the initial status UI and ordinary mobile host scaffolding. Hard real-time audio, MIDI, plugin, persistence, and product-domain architecture remain outside this implementation and require later evidence-backed decisions. Repository documents and loop state form the durable control plane for future research and implementation.
