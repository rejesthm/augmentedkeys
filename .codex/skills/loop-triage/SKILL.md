# AugmentedKeys Loop Triage

1. Read the project controls named in `LOOP.md`.
2. Inspect project memory, repository status, and permitted verification evidence.
3. Separate facts, command evidence, inferences, recommendations, blockers, and missing evidence.
4. Stop if any action exceeds L1 report-only scope.
5. Update only `STATE.md`, `.loop/progress.md`, and `loop-run-log.md`.
6. Recommend exactly one next task from the active, owner-approved milestone.
7. Request owner approval before the proposed task begins.

Do not implement fixes, launch agents, schedule automation, change dependencies, decide architecture, commit, push, merge, sign, release, or deploy.
